# Product: готові файли для імпорту

Кожна версія — це **один файл**, у якому вже є англійський оригінал і
український переклад:

| Версія | Файл для завантаження |
|---|---|
| v1 | `04-product-v1.en-uk.json` |
| v2 | `04-product-v2.en-uk.json` |
| v3 | `04-product-v3.en-uk.json` |

Після імпорту в таблиці одразу з’являються ключ, англійський оригінал і
український переклад. Перед імпортом у проєкті має бути додана українська мова.

Між v1, v2 і v3 навмисно змінені формулювання. Плейсхолдери `{{number}}`,
`{{sku}}`, `{{rating}}`, `{{count}}`, `{{date}}` і `{{store}}` однакові в
оригіналі та відповідному перекладі. Звичайні JSON-файли лише з оригіналом
також можна імпортувати, як і раніше.
