# Приклад нового проєкту: Northstar Market

Це готовий набір англомовних JSON-файлів для створення складнішого тестового
проєкту в LocaleFlow. Кожен файл потрібно імпортувати як **окрему сторінку**.

## Як створити проєкт

1. На екрані проєктів створи проєкт `Northstar Market`.
2. Залиш мову оригіналу `en / English`.
3. У редакторі додай цільову мову, наприклад `uk / Українська`.
4. Імпортуй файли по одному через «Нова сторінка».

| Файл | Назва сторінки | Назва першої версії |
|---|---|---|
| `01-shared.en.json` | `Shared` | `Initial shared UI` |
| `02-home.en.json` | `Home` | `Initial home page` |
| `03-catalog.en.json` | `Catalog` | `Initial catalog` |
| `04-product.en.json` | `Product` | `Initial product page` |
| `05-checkout.en.json` | `Checkout` | `Initial checkout flow` |
| `06-account.en.json` | `Account` | `Initial account area` |

### Наступні версії Shared

Після створення сторінки `Shared` імпортуй ці файли через «Додати версію»:

| Порядок | Файл | Назва версії |
|---|---|---|
| 2 | `01-shared-v2.en.json` | `Navigation and search update` |
| 3 | `01-shared-v3.en.json` | `Account and accessibility update` |

Обидва файли є повними знімками сторінки, а не списками окремих змін. У них
спеціально поєднані незмінені, змінені, додані та видалені ключі для перевірки
перенесення перекладів і статусу `OUTDATED`.

Після імпорту в лівій панелі з'являться шість незалежних сторінок. Однакові
назви вкладених ключів у різних файлах не конфліктують, оскільки кожна сторінка
має власні версії та переклади.

## Приклади глосарію та перекладів

- `glossary.uk.reference.json` містить 16 рекомендованих термінів із визначеннями,
  примітками та прикладами. Їх можна по одному додати на сторінці «Глосарій».
- `translation-examples.uk.reference.json` містить приклади українських перекладів
  для всіх шести сторінок. Поле `key` допомагає швидко знайти потрібний рядок.

Ці два файли є **довідковими**: вони містять масиви об'єктів і не призначені для
імпорту через «Нова сторінка». Поточний інтерфейс не має масового імпорту
глосарію або готових перекладів, тому приклади потрібно переносити у відповідні
поля вручну.

## Обмеження формату

LocaleFlow приймає вкладені JSON-об'єкти, але кінцеве значення кожного ключа
має бути непорожнім рядком. Масиви, числа, `true`/`false` і `null` у файлах
локалізації не підтримуються. Наприклад, плейсхолдери на кшталт `{{count}}`
зберігаються всередині рядка та мають залишатися незмінними у перекладі.
